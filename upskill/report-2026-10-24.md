## Learning Plan

### AI / LLM Engineering

**AI / LLM application engineering (LangChain/LangGraph, RAG, agents, evals)** `[Domain / Tooling]` — ~30h
- [LangChain for LLM Application Development (DeepLearning.AI)](https://www.deeplearning.ai/courses/langchain) — beginner-friendly, builds chatbots and RAG pipelines
- [The Complete LangChain & RAG Developer Course 2026 (Udemy)](https://www.udemy.com/course/langchain-rag-course/) — end-to-end RAG with vector stores
- [Learn LangChain.js (Scrimba)](https://scrimba.com/learn/langchainjs) — JS/TS-focused, fits your Node/TypeScript stack

Study direction: You already have strong Node/TypeScript and PostgreSQL skills — leverage them. Skip Python ML/math foundations; start directly with LLM APIs (OpenAI/Claude/Gemini), prompt engineering, and LangChain/LangChain.js orchestration. Use pgvector on your existing Postgres for RAG, then add evaluation (RAGAS) and basic agent loops. Three of six demand sources (airslate, CoverYou, Upstack) explicitly want this — record the gaps by shipping a RAG mini-app over one of your existing repos as the capstone.

### Cloud & Infrastructure

**Kubernetes** `[Hard]` — ~20h
- [Kubernetes for the Absolute Beginners – Hands-on Labs (KodeKloud, via Udemy)](https://www.udemy.com/course/learn-kubernetes/) — hands-on labs, widely recommended on r/kubernetes and r/devops for practical learners
- [Official Kubernetes Docs: Concepts](https://kubernetes.io/docs/concepts/) — use as reference once you have the basics
- [Kubernetes Up & Running (O'Reilly)](https://www.oreilly.com/library/view/kubernetes-up-and/9781098110192/) — concise, production-focused reference

Study direction: You already know Docker, AWS EC2, and CI/CD — skip Chapter 1 on containers and images. Start at Pod scheduling, work through Services, Deployments, ConfigMaps/Secrets, and Ingress. Get `kubectl` fluency and manifest authoring solid before touching Helm. Add an EKS or AKS deployment as the capstone (Thales wants K8s, diconium wants Azure/AKS — either cloud satisfies both phrasings).

### Data

**DynamoDB (single-table design, indexes, streams)** `[Hard]` — ~15h
- [Getting Started with DynamoDB (AWS official docs)](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/GettingStartedDynamoDB.html) — hands-on CRUD and table creation
- [The DynamoDB Book (Alex DeBrie)](https://www.dynamodbbook.com/) — the canonical guide to single-table design
- [Master AWS DynamoDB (Coursera / Packt)](https://www.coursera.org/learn/packt-master-aws-dynamodb-qwba0) — structured course with hands-on exercises

Study direction: You know PostgreSQL and MongoDB well, so the shift is mental (access-pattern-first modeling). Skip NoSQL basics and relational comparisons; start at partition/sort key design, GSIs/LSIs, and single-table design patterns. DynamoDB Streams + Lambda is the natural bridge into the AWS serverless/IaC Medium gap (Upstack's full stack: Lambda, API Gateway, SQS/SNS/EventBridge, CDK/Terraform).

### Observability

**ELK / log aggregation stack** `[Tooling]` — ~10h
- [Elastic Stack Monitoring: ES, Kibana, Agents/Beats, Logstash (Udemy, updated 4/2026)](https://www.udemy.com/course/elastic-stack-monitoring-es-kibana-agentsbeats-logstash/) — 9h hands-on course covering indices, mappings, Kibana dashboards, Beats/Fleet, and alerting
- [Introduction to the Elastic Stack (ELK) — Free (Udemy)](https://www.udemy.com/course/introduction-elk-stack/) — free 1h primer by an Elastic Gold Contributor; useful as a zero-cost first pass
- [Complete Guide to Elasticsearch (Bo Andersen, Udemy)](https://www.udemy.com/course/elasticsearch-complete-guide/) — deep Elasticsearch-focused reference once you want query DSL and aggregations

Study direction: You already run Prometheus + Grafana + Loki in production on Instant Panel — skip every "what is observability" lecture. Go straight to Elasticsearch architecture (indices, shards, mappings), then Kibana dashboards/queries, then Beats/Elastic Agent shipping. Capstone: replace or augment Loki on Instant Panel with an Elastic Agent → Elasticsearch pipeline and build one ops dashboard.

### Testing & Quality

**Automated testing (Jest, supertest, E2E, coverage)** `[Tooling]` — ~15h
- [Master API Testing and Automation using TypeScript (Dilpreet Johal, Udemy)](https://www.udemy.com/course/master-api-test-automation/) — builds a Supertest + Jest + TypeScript framework incl. auth handling and CI integration; updated 12/2025
- [Unit Testing in Node.js with Jest — e2e Testing & more (Udemy, updated 4/2026)](https://www.udemy.com/course/unit-testing-in-nodejs-with-jest/) — covers mocking, controllers/middleware tests, e2e with mongodb-memory-server, coverage
- [Mastering Jest Testing with TypeScript and Node.js (Yanis Smilga, Udemy)](https://www.udemy.com/course/mastering-jest-testing-with-typescript-and-nodejs/) — TS-native Jest setup, mocks/stubs/spies, error handling

Study direction: You already have a 10-file suite on Instant Panel — skip the "what is a test" and first-unit-test lectures. Start at module mocking (mock RabbitMQ, Redis, Prisma, and webhook providers), supertest integration tests against auth-token flows (your KYC/payout endpoints are the perfect material), coverage reports, then wire the suite into your existing GitHub Actions pipelines.

### Mobile

**React Native (Expo, native components, navigation)** `[Hard]` — ~25h
- [React Native – The Practical Guide (Maximilian Schwarzmüller, Udemy)](https://www.udemy.com/course/react-native-the-practical-guide/) — hands-on, builds real apps
- [Complete React Native Developer (Zero to Mastery)](https://zerotomastery.io/courses/learn-react-native/) — large-scale iOS/Android apps
- [Expo Documentation](https://docs.expo.dev/) — official reference for the modern React Native toolchain

Study direction: Your React/Next.js skills transfer directly — skip React basics; start at Expo setup, native navigation (React Navigation), platform-specific code, and native device APIs (camera, push notifications). Build a small companion app to Cashbackwallah as the capstone — CoverYou's recorded gap explicitly pairs LLM integrations with React Native contribution, so this doubles as interview talking material.

### Soft Skills & Ways of Working

**In-house engineering practices (code review, mentoring, on-call, ceremonies)** `[Soft]` — ~10h
- [Fundamentals of Effective Code Review Practices (Coursera)](https://www.coursera.org/learn/fundamentals-of-effective-code-review-practices) — foundations and practical skills for conducting reviews
- [Code Review Best Practices: The Complete Guide for Engineering Teams 2026 (dev.to)](https://dev.to/rahulxsingh/code-review-best-practices-the-complete-guide-for-engineering-teams-2026-52a4) — PR size, review speed, feedback, automation

Focus on PR hygiene (small PRs, clear descriptions), review etiquette (nit vs. blocking), on-call rotation vocabulary, and sprint ceremonies. Practice by opening PRs on cheapship/instant-panel and requesting external review.
