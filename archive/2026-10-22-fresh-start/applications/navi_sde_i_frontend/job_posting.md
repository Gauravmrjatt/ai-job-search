UI Engineer I — Navi

About Navi

Navi is a technology-driven financial services company focused on simplifying finance for customers through scalable digital products. Founded in 2018, Navi operates across Loans, UPI, Insurance, Mutual Funds, and Digital Gold, serving millions of customers across India.
Navi focuses on solving real customer problems through technology, fast execution, and strong ownership. Employees are encouraged to take responsibility early, make decisions, and create measurable impact.

About the Role

Navi is looking for a UI Engineer I to join its frontend engineering team. This role is designed for early-career engineers who have strong frontend fundamentals, enjoy problem-solving, and want to build reliable user-facing products.
The role emphasizes JavaScript fundamentals, frontend development, clean code, debugging, performance, testing, and collaboration.

Key Responsibilities

- Analyze product and technical problems and develop efficient solutions.
- Build user-facing web interfaces using JavaScript, HTML, and CSS.
- Develop applications using React.js or similar frontend frameworks.
- Translate product requirements into clean, functional, and maintainable UI.
- Focus on application performance and customer experience.
- Debug frontend issues and understand code behavior systematically.
- Apply basic security best practices while developing features.
- Write unit tests covering happy paths, edge cases, and error scenarios.
- Develop higher-level tests with guidance from senior engineers.
- Write readable, organized, and maintainable code.
- Collaborate with engineers, designers, and product teams.
- Contribute to delivering reliable and high-quality frontend experiences.
